# App icons

Ikony aplikacji i obrazy do udostępniania, wszystkie z jednego znaku „Horyzont”.

- `favicon.svg`: kafelek, w ciemnym motywie przeglądarki rozjaśnia niebo.
- `icon-tile.svg` i `icon-16` do `icon-1024` (PNG): zaokrąglony kafelek, promień 112/512. Rozmiary 16, 32, 48, 64, 96, 128, 192, 256, 384, 512 i 1024.
- `apple-touch-icon-180.png`: pełny kwadrat bez zaokrągleń, iOS zaokrągla sam.
- `icon-maskable.svg`, `icon-maskable-192.png`, `icon-maskable-512.png`: pełny kwadrat, treść w bezpiecznym polu 80%, do manifestu PWA z `"purpose": "maskable"`.
- `og-image-light.png` i `og-image-dark.png`: 1200×630px, układ pionowy z podtytułem na `background` jasnego i ciemnego motywu.

Fragmenty do `<head>` i manifestu są w głównym README, w sekcji Logo.
