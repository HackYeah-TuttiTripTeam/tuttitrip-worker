# Icons

Wybrane ikony z **Keyline Icons** (keylineicons.com, licencja MIT), styl stroke z zaokrąglonymi rogami, siatka 24×24, linia 2px, skopiowane 1:1 z `@keyline-icons/react`. Rysowane w `currentColor`: jako `<img>` pokazują się w czerni, w aplikacji dziedziczą kolor tekstu.

W aplikacji: `npm i @keyline-icons/react` i `import { ThumbsUp } from "@keyline-icons/react"`; dwutonowe (`/two-tone`) tylko dla gwiazdy „kultowe”, tarczy „zweryfikowana” i iskier asystenta. Przypisania: kciuki = głosy, minus = obojętnie, check / x / pytajnik = trzy stany, alert = problem i decyzja, info = wskazówka, gwiazda = kultowe, tarcza = zweryfikowana, deszcz / księżyc / kłódka = przeplanowanie, trasa = przejazd, pinezka = miejsce, kalendarz = plan, portfel = wydatki, ludzie = grupa, iskry = asystent, paragon = wydatek, kubek = przerwa, łóżko = nocleg, zegar = godziny.
