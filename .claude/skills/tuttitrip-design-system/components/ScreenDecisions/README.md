# ScreenDecisions

Decyzja o propozycji planu (członek): kto już się zdecydował, czego jeszcze nie oceniłeś, i trzy odpowiedzi.

- Nagłówek mówi kto i co („Ania wysłała plan Gdańska”), pod nim wersja i sprawiedliwość jednym zdaniem.
- Lista osób ze statusem: zatwierdził (`want`), przez link (osoba bez konta), uwagi (`decline` + cytat), ocenia za nią host (przerywany, bo to nie jej głos), Ty.
- Zanim zatwierdzisz: miejsca bez Twojej oceny z `RatingControl` w wersji poziomej 48px. Weto to „Nie” + powód.
- Stały dół: „Odrzuć” (ghost), „Uwagi” (outline, otwiera pole jednego zdania) i „Zatwierdź plan” (primary: bezpieczny krok, bo niczego nie kosztuje innych).
- Host widzi ten sam ekran z przyciskiem „Przypomnij” przy osobach bez głosu i zbiorczym „Zastosuj uwagi”, który przelicza plan.
