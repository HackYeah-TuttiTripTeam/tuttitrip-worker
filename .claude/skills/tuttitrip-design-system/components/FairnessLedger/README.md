# FairnessLedger

Księga sprawiedliwości dla hosta: miejsca z własnej listy i zadowolenie każdej osoby w każdej dziedzinie.

- Liczby w `display` z cyframi tabelarycznymi, wyrównane do prawej. Bez kolorowania wszystkich komórek: tylko wartości poniżej 40 dostają `decline-soft`. Reszta to czysta tabela.
- Tytuł zwykłym zdaniem („Kto ile zyskuje”), pod tabelą jedno zdanie wyjaśnienia najniższej wartości.
- Telefon: pierwsza kolumna przyklejona, przewijanie poziome w kartce.

**Z rejestru**

- `npx shadcn@latest add table`.
