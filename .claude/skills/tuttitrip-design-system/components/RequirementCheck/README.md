# RequirementCheck

Wymagania noclegowe dla oferty i nocy: spełnione, niespełnione, niepotwierdzone, zawsze z cytatem z oferty.

- Trzy stany: pełne koło `want-soft` z checkiem, pełne koło `danger-soft` z krzyżykiem, koło z przerywanym obrysem i znakiem zapytania (reguła linii: przerywane = niepewne).
- Cytat z oferty w cudzysłowie „…” pod wymaganiem, w `muted-foreground`. Brak wzmianki: „Oferta nie wspomina o …”, bez cudzysłowu.
- Lista w jednej kartce, wiersze oddzielone włoskową linią.
