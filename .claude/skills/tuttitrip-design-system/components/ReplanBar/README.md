# ReplanBar

Jedno dotknięcie podmienia resztę dnia na alternatywy policzone z góry.

- Pytanie zwykłym zdaniem („Coś się zmieniło?”) i trzy pigułki outline z ikoną: Pada, Zmęczeni, Zamknięte.
- Przeliczenie jest natychmiastowe (bez modelu); nowy fragment `PlanTimeline` pokazuje zmiany.
- Zmiany dotyczące innych osób idą do hosta jako `ApprovalCard`; członek widzi „Czeka na decyzję Ani”.
- Tylko w trakcie podróży, nad dzisiejszym dniem.
