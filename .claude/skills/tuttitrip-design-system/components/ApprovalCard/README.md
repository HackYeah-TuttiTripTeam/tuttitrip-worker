# ApprovalCard

Karta zatwierdzenia jako bilet: część z decyzją, perforacja, odcinek z przyciskami. Każde działanie dotykające innych osób albo pieniędzy czeka tu na hosta.

- Dotyczy przekroczenia budżetu, zapisu do kalendarza, otwarcia wyszukiwania noclegów, zmian z przeplanowania dotyczących innych osób. TuttiTrip niczego nie kupuje ani nie rezerwuje sam.
- Tło `warning-soft`, `radius-xl`, perforacja `warning` 2px przerywana z wycięciami w kolorze tła. Bez obrysu i bez cienia.
- Nad tytułem „Czeka na Twoją decyzję” (nie nazwa komponentu), tytuł mówi, co i ile.
- „Odrzuć” (outline) i „Zatwierdź” (`ink`, z kwotą w etykiecie).

**Z rejestru**

- Zatwierdzanie: `npx shadcn@latest add @aceternity/stateful-button`.
