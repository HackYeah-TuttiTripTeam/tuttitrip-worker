# ScreenSettings

Ustawienia użytkownika: profil, własne potrzeby, wygląd, powiadomienia, konto.

- Sekcje to kartki z listą wierszy 44px; etykieta sekcji w `label` `muted-foreground`, nie wersalikami.
- „Twoje potrzeby” trzymają domyślne ograniczenia, pulę ważności i dietę, które wchodzą do każdej nowej podróży. Wartość skrótem po prawej, dotknięcie otwiera edytor (`ImportancePool`, suwaki ograniczeń).
- Wygląd: przełącznik segmentowy Jasny / Ciemny / Jak w systemie i „Większy tekst” (skala `body` 17 → 19px).
- Przełączniki: pigułka 52×32, włączony `primary`.
- „Usuń konto” jako ghost w kolorze `destructive`, zawsze z dialogiem potwierdzenia. Hasła i e-mail zmienia Auth0 (link wychodzący).
